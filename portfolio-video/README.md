# ویدیوی معرفی پروژه ماه‌ورا

این پوشه شامل Captureهای واقعی، Composition برنامه‌پذیر Remotion، موسیقی و افکت‌های صوتی اختصاصی و خروجی نهایی ویدیوی معرفی MAHVARA است.

## خروجی‌های V2

- ویدیو: `renders/MAHVARA-Portfolio-V2.mp4`
- پوستر: `renders/MAHVARA-Karlancer-Poster.png`
- مدت ویدیو: ۱۰۴٫۰۶ ثانیه
- تصویر: ۱۹۲۰×۱۰۸۰، ۶۰ فریم‌برثانیه، H.264 High، `yuv420p` با رنگ BT.709
- صدا: AAC، استریو، ۴۸ کیلوهرتز، حدود ۳۲۰ کیلوبیت‌برثانیه
- پوستر: PNG با ابعاد دقیق ۸۰۰×۴۸۰
- گوینده: ندارد

V2 یک جریان متصل واقعی را نمایش می‌دهد: جست‌وجوی محصول، صفحهٔ محصول، علاقه‌مندی و سبد، Checkout آزمایشی، سفارش در حساب مشتری و همان سفارش در پنل مدیریت. Captureهای V2 در `captures/v2/` و Composition آن در `source-v2/` نگهداری می‌شوند. موسیقی ۱۱۲ BPM و افکت‌های UI نیز در `scripts/generate-audio-v2.mjs` به‌صورت الگوریتمی و اختصاصی تولید شده‌اند.

نسخهٔ اول با نام `renders/MAHVARA-Portfolio-Final.mp4` حفظ شده و بازنویسی نشده است.

## نسخهٔ محلی V1

- فایل: `renders/MAHVARA-Portfolio-Final.mp4` (آرشیو محلی)
- مدت: ۱۰۴٫۰۴ ثانیه
- تصویر: ۱۹۲۰×۱۰۸۰، ۶۰ فریم‌برثانیه، H.264
- صدا: AAC، استریو، ۴۸ کیلوهرتز، حدود ۳۲۰ کیلوبیت‌برثانیه
- حجم: حدود ۷۰٫۷ مگابایت
- زبان تمام نوشته‌های روایی: فارسی
- گوینده: ندارد

موسیقی پس‌زمینه و افکت‌های Whoosh، Impact، Click و Rise در `scripts/generate-audio.mjs` به‌صورت الگوریتمی و اختصاصی ساخته شده‌اند و هیچ فایل صوتی ثالث در خروجی استفاده نشده است.

## ساختار

```text
portfolio-video/
├── source/          Composition و Motion Design در Remotion
├── source-v2/       Composition و پوستر نسخهٔ دوم
├── captures/        ضبط‌های واقعی دسکتاپ و موبایل
├── assets/          فونت و نشان برند مورد استفاده در تدوین
├── audio/           موسیقی و افکت‌های صوتی تولیدشده
├── renders/         فایل MP4 نهایی
├── scripts/         Capture، تولید صدا، همگام‌سازی و بازنشانی Demo
├── quality-control/ فریم‌ها و Contact Sheet بازبینی
├── STORYBOARD.md    زمان‌بندی و پیام هر صحنه
├── STORYBOARD-V2.md زمان‌بندی و روایت نسخهٔ دوم
└── README.md
```

پوشه `public/` هنگام Render از روی Assetهای لازم ساخته می‌شود و فقط ورودی‌های مورد نیاز Remotion را در خود دارد.

برای مرتب‌ماندن Repository، فقط Deliverableهای نهایی V2، Captureهای لازم، Sound Design V2 و Source مربوط به V2 در GitHub نگهداری می‌شوند. Cacheها، Previewهای کنترل کیفیت، وابستگی‌های نصب‌شده و نسخهٔ آرشیوی V1 فقط در محیط محلی باقی می‌مانند.

## بازتولید V2

پیش از Capture، سایت باید در `http://localhost:3010` اجرا شود و دیتابیس Demo آماده باشد.

```powershell
npm install
npm run capture:v2
npm run audio:v2
npm run poster:v2
npm run render:v2
```

دستور Render از Chrome نصب‌شده در مسیر استاندارد ویندوز استفاده می‌کند. در سیستم دیگر می‌توان مقدار `--browser-executable` را در `package.json` تغییر داد.

اسکریپت Capture مقادیر ورود حساب‌های Demo را پشت‌صحنه از `.env` پروژه می‌خواند؛ رمز عبور، Secret و فایل محیطی هرگز روی تصویر ظاهر نمی‌شوند. `scripts/reset-demo.mjs` فقط داده‌های تجارت مربوط به همان مشتری Demo محلی را برای تکرار تمیز Capture بازنشانی می‌کند.
