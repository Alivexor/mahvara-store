# هویت برند ماه‌ورا / MAHVARA

«ماه‌ورا» نامی کوتاه، خوش‌آوا و مستقل برای مفهوم روشنایی آرام و انتخاب فراتر از ظاهر است. جست‌وجوی مستقیم وب پیش از انتخاب، برند Beauty هم‌نام آشکاری نشان نداد؛ برای استفاده تجاری همچنان استعلام حقوقی علامت و دامنه ضروری است.

## سیستم بصری

- Primary: Burgundy `#6E2438`
- Primary dark: `#4F1828`
- Secondary: Sage `#75806C`
- Accent: Earth gold `#B78C62`
- Ivory: `#F7F2EB`
- Surface: `#FFFDF9`
- Ink: `#251D1F`
- Muted: `#756C68`
- Border: `#E6DDD3`
- Typeface: Vazirmatn Variable، Self-hosted از npm package
- Radius: 12 / 18 / 28px
- Shadows: کم‌کنتراست، گرم، مناسب کارت‌های Premium
- Spacing: پایه 4px با گام‌های اصلی 8، 12، 16، 24، 32، 48، 64

نماد از هلال و درخشش چهارجهته ساخته شده و Wordmark فارسی/لاتین در `public/brand` قرار دارد. تصاویر Hero و چهار خانواده محصول با ابزار داخلی Image Generation و Promptهای Original تولید شده‌اند؛ هیچ تصویر برند یا Asset دارای Watermark استفاده نشده است.
